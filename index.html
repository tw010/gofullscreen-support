SUPPORT REQUESTS

GoFullScreen Support

Report a problem, ask a question, or suggest an improvement. The request form guides you through the useful details without collecting anything automatically.

Open a support request Try the capture test page

Requests are handled through GitHub Issues, so GitHub may ask you to sign in. GoFullScreen never attaches your active page, screenshot, or settings automatically.

Expected Chrome security restriction

Chrome does not allow extensions to run the page scripts required for full-page capture on the Chrome Web Store, its Developer Dashboard, chrome:// pages, the built-in PDF viewer, or pages belonging to other extensions. This is not a GoFullScreen error and does not need a support request.

Before you submit

These three quick steps often solve the issue or provide the details needed for a useful response.

1

Check the page type

Protected Chrome pages cannot be captured. If you are on one of the page types listed above, this is expected browser behavior.

2

Try the test page

Use the safe public capture page to check whether the issue is specific to one website or happens everywhere.

3

Copy diagnostics

Open GoFullScreen Settings and select Copy diagnostic info. Paste that text into the request form.

Helpful information

  • What you expected and what happened instead.
  • Short steps that reproduce the problem.
  • The copied diagnostic info from Settings.
  • A public example URL or the type of page involved, when safe to share.

Protect your privacy

Do not submit passwords, private page URLs, personal messages, account details, or unredacted screenshots. The diagnostic copy intentionally excludes page URLs and screenshots.
